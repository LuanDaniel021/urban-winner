
# Grupo 5 - Plataforma web

## Objetivo

Desenvolver uma página web de acesso aberto para orientar o descarte correto de equipamentos eletroeletrônicos.

## Requisitos

- Apresentar um guia de descarte por tipo de equipamento, com base na relação de produtos do Anexo I do Decreto nº 10.240/2020.
- Incluir uma lista de verificação para preparar o equipamento antes do descarte, incluindo desligá-lo, separar pilhas e baterias removíveis e apagar dados pessoais.
- Apresentar um mapa ou localizador dos pontos de recebimento levantados pelo Grupo 2.

## Entrega

Disponibilizar o código-fonte do projeto no GitHub.

## Funcionalidades

- Busca de equipamentos e filtros por categoria.
- Orientações de preparação antes do descarte, incluindo desligar o equipamento, separar pilhas e baterias removíveis e apagar dados pessoais.
- Checklist interativo com indicador de progresso.
- Acesso aos localizadores de pontos da ABREE e da Green Eletron.
- Referências ao Decreto nº 10.240/2020 e ao SINIR.

## Como executar

O projeto é estático e não requer instalação de dependências nem etapa de compilação. Abra `index.html` em um navegador. Para executar um servidor local, use qualquer servidor HTTP estático na pasta do projeto.

## Referências

- [Decreto nº 10.240/2020](https://www.planalto.gov.br/ccivil_03/_ato2019-2022/2020/decreto/d10240.htm)
- [SINIR - Eletroeletrônicos](https://www.sinir.gov.br/perfis/logistica-reversa/logistica-reversa/eletroeletronicos/)
- [Pontos de recebimento ABREE](https://abree.org.br/pontos-de-recebimento)
- [Localizador Descarte Green - Green Eletron](https://greeneletron.org.br/descarte-green/)

Os equipamentos apresentados são exemplos e não substituem a consulta à relação integral do Anexo I nem a confirmação de aceitação, condições e horários diretamente com o ponto de recebimento. A disponibilidade dos pontos pode mudar.
